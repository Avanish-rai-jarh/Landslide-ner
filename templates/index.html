HOW IT WORKS

AI + GIS in one workflow

The browser sends selected coordinates to Flask. Flask first checks whether the location belongs to one of the eight supported Northeast Indian states.

For supported locations, Flask retrieves the nearest environmental dataset point and sends the required features to the saved Random Forest model.

Stack: Python · Flask · Scikit-learn · Random Forest · Leaflet · OpenStreetMap · GeoJSON
